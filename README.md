# Motion Orbit

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)

Motion Orbit is a Flutter fitness app for setting up and managing a personal fitness profile. Use the guided setup to record your goals and training preferences, then review or update them from your dashboard.

## Features

- Guided onboarding for basic profile details, fitness goals, and experience level.
- Optional workout preferences for training location, equipment, training days, and session duration.
- Profile data stored locally on the device.
- Dashboard with Home, Workout, Progress, and Profile sections.
- Edit your profile and preferences after setup.

The Workout and Progress sections are currently placeholders. Workout planning, workout sessions, and progress tracking are not implemented yet.

## Getting Started

### Requirements

- Flutter SDK compatible with the version constraint in `pubspec.yaml`.
- A Flutter-supported device or emulator.

### Run the app

```sh
flutter pub get
flutter run
```
